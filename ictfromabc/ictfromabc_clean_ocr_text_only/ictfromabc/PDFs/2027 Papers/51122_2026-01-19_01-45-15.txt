Boolean Algebraic Laws

1. Double complement law
ද්විත්ව ප්‍රතිලෝම න්‍යාය

A = A

2. Idempotent law
තදේවභාවී න්‍යාය

A + A = A
A . A = A

3. Identity law
සර්වසාම්‍ය න්‍යාය

A . 0 = 0
A . 1 = A
A + 0 = A
A + 1 = 1

4. Inverse law / complement law
ප්‍රතිලෝම න්‍යාය

A . A = 0
A + A = 1

5. Commutative law
න්‍යාදේශ න්‍යාය

A . B = B . A
A + B = B + A

6. Associative law
සංඝටන න්‍යාය

A . (B. C) = (A. B). C
A + (B + C) = (A + B) + C

7. Distributive law
විඝටන න්‍යාය

A . (B + C) = A. B + A. C
A + (B. C) = (A + B). (A + C)

8. De Morgan’s Law
ද මුවාර් ප්‍රමේය

A. B = A + B
A + B = A. B

9. Redundancy law
සමතිරික්ත න්‍යාය

A + A. B = A
A + A. B = A + B

Building blocks of CPU
CPU හි තැනුම් ඒකක

Adders
ආකලක

An adder is a digital logic circuit that
performs binary addition.
ආකලකයක් යනු ද්විමය එකතු කිරීම සිදු කරන
අංකිත තාර්කික පරිපථයකි.

1. Half Adder
අර්ධ ආකලකය

Adds two single-bit binary numbers and
produces two outputs called Sum (A ⊕ B)
and Carry (A • B), without considering any
carry input from a previous addition.
පෙර සිදු කරන ලද එකතු කිරීමකින් කිසිදු රැගෙන
යාමේ ආදානයක් සැලකිල්ලට නොගෙන, තනි-බිටු
සහිත ද්විමය සංඛ්‍යා දෙකක් එකතු කර Sum එක
(A ⊕ B)  සහ Carry එක  (A • B) ලෙසින්
හඳුන්වන ප්‍රතිදාන දෙකක් නිපදවයි.

Inputs
ආදාන
Two single-bit binary numbers, usually
denoted as A and B.
සාමාන්‍යයෙන් A සහ B ලෙස දැක්වෙන තනි-බිටු
ද්විමය සංඛ්‍යා දෙකක්.

Outputs
ප්‍රතිදාන

Sum (S) - This is the result of adding the
two input bits.
මෙය ආදාන බිටු දෙක එකතු කිරීමේ ප්‍රතිඵලයයි.

Carry (C) - This indicates if there is a carry-
out from the addition. A carry is produced
when the sum of the two bits is greater
than what can be represented by a single
bit (ex:- greater than 1).
රැගෙන යාම (C) - එකතු කිරීමෙන් ගෙනයාමක්
තිබේද යන්න මෙයින් පෙන්නුම් කරයි. බිටු දෙකේ
එකතුව තනි බිටුවකින් (එනම්, 1 ට වඩා වැඩි)
නියෝජනය කළ හැකි ප්‍රමාණයට වඩා වැඩි වූ විට
රැගෙන යාමක් නිර්මාණය වේ.
Functionality
ක්‍රියාකාරීත්වය

The Sum (S) output is generated using an
XOR gate, which performs the binary
addition of A and B.
එකතු (S) ප්‍රතිදානය උත්පාදනය කරනු ලබන්නේ
XOR ද්වාරයක් භාවිතයෙන් වන අතර එය A සහ
B හි ද්විමය එකතු කිරීම සිදු කරයි.

The Carry (C) output is generated using an
AND gate, which produces a 1 only when
both A and B are 1, indicating a carry over.
රැගෙන යාම (C) ප්‍රතිදානය ජනනය කරනු
ලබන්නේ AND ද්වාරයක් භාවිතයෙන් වන අතර,

Combinational Circuits
සංයුක්ත පරිපථ

Combinational circuits are types of digital

the current input values.

There is no concept of memory or past
input states in these circuits.

ප්‍රතිදානය එහි ආදානයට නැවත ලබා දීමේ
ක්‍රියාවලියකි.
