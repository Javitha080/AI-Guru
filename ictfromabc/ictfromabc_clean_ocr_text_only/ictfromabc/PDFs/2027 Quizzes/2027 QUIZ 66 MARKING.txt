4. In ASCII, what is the difference between the value of an uppercase letter and its corresponding lowercase
letter?
ASCIIහි, uppercase අකුරක අගය සහ ඊට අනුරූප lowercase අකුරක අතර වෙනස කුමක්ද?
1)  16
2)  26
3) 32
4) 48
5) 64
Answer: 3)

How ASCII assigns values / ASCII අගයන් පවරන ආකාරය:

ASCII assigns the following values to letters / ASCII අකුරු වලට පහත අගයන් පවරයි,

Uppercase letters ('A' to 'Z') have ASCII values from 65 to 90.
Uppercase අකුරු වලට ('A' to 'Z')  65 සිට 90 දක්වා ASCII අගයන් ඇත.

Lowercase letters ('a' to 'z') have ASCII values from 97 to 122.
Lowercase අකුරු වලට ('a' to 'z')  97 සිට 122 දක්වා ASCII අගයන් ඇත.

Example / උදාහරණය:
The ASCII value of 'A' is 65 / 'A' හි ASCII අගය 65 වේ.
The ASCII value of 'a' (lowercase) is 97 / 'a' හි ACII අගය 97 වේ.

Difference between 'A' and 'a' / 'A' සහ  'a' අතර වෙනස = 97 – 65 = 32

General rule / සාමාන්‍ය රීතිය:

The difference between the ASCII value of any uppercase letter and its corresponding lowercase letter is
always 32.
ඕනෑම uppercase අකුරක ASCII අගය සහ එහි අනුරූප lowercase අකුර අතර වෙනස සැමවිටම 32 වේ.
