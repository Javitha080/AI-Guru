3. Which of the following is true about number systems?
සංඛ්‍යා පද්ධති සම්බන්ධයෙන් පහත සඳහන් දේවලින් සත්‍ය වන්නේ කුමක්ද?
A. The number of unique digits used in a number system is equal to its base.
සංඛ්‍යා පද්ධතියක භාවිතා වන අනන්‍ය සංඛ්‍යා ගණන එහි පාදයට සමාන වේ.

B.  In the binary number system, the largest 3-digit binary number is equivalent to 7 in decimal.
ද්විමය සංඛ්‍යා පද්ධතියේ, විශාලතම ඉලක්කම්  3 ක ද්විමය සංඛ්‍යාව දශමයෙන් 7 ට සමාන වේ.

C. In the octal number system, each digit can be represented as a group of 4 binary bits.
අෂ්ඨමය සංඛ්‍යා පද්ධතියේ, සෑම ඉලක්කමක්ම ද්විමය බිටු 4ක කණ්ඩායමක් ලෙස නිරූපණය කළ හැක.
1)  A only.
A පමණි.
2)  B only.
B පමණි.
3) A and B only.
A හා B පමණි.
4) B and C only.
B හා C පමණි.
5) All the of above.
ඉහත සියල්ලම.
