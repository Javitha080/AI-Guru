1. What type of data access method is used by magnetic tapes?
චුම්බක පටි භාවිතා කරන්නේ කුමන ආකාරයේ දත්ත ප්‍රවේශ ක්‍රමයක්ද?

1) Random access /සසම්භාවි ප්‍රවේශය
2) Sequential access / අනුක්‍රමික ප්‍රවේශය
3) Direct access / සෘජු ප්‍රවේශය
4) Index access / දර්ශක ප්‍රවේශය
5) Parallel access / සමාන්තර ප්‍රවේශය

3. Which is NOT a feature of EBCDIC?
EBCDIC හි විශේෂ අංගයක් නොවන්නේ කුමක්ද?
1) Uses an 8-bit encoding system / 8-බිටු කේතන පද්ධතියක් භාවිතා කරයි.
2) Primarily used in IBM mainframes.
ප්‍රධාන වශයෙන් IBM ප්‍රධාන රාමු (mainframe) පරිගණකවල භාවිතා වේ.

3) Characters are arranged non-sequentially / අනුලක්ෂණ අනුක්‍රමික නොවන ආකාරයෙන් සකසා ඇත.
4) Supports 256 characters / අනුලක්ෂණ 256 ක් සඳහා සහාය දක්වයි.
5) Compatible with modern web applications / නූතන වෙබ් යෙදුම් සමඟ ගැළපේ.
