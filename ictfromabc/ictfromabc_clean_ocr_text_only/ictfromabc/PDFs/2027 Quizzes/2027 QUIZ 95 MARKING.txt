නිරූපණය කෙරේ. උදාහරණයක් ලෙස:

0 → 0000
5 → 0101
9 → 1001

Statement / ප්‍රකාශය B : සත්‍ය / True

This is incorrect because leading zeros are required in the BCD code to maintain the 4-bit structure for
each digit. For example:
මෙය වැරදියි, මන්ද සෑම ඉලක්කමකටම බිටූ 4ක ව්‍යුහය පවත්වා ගැනීම සඳහා BCD කේතයේ ප්‍රමුඛ ශුන්‍ය
අවශ්‍ය වේ. උදාහරණයක් ලෙස:
The number 007 in BCD must be represented as 0000 0000 0111 to explicitly encode all digits, including
the leading zeros. Ignoring the leading zeros would change the meaning of the number, which violates the
rules of BCD representation.

The BCD value and the base 2 binary value of the same decimal number are not the same. For example:
එකම දශම සංඛ්‍යාවේ BCD අගය සහ පාදම 2 ද්විමය අගය සමාන නොවේ. උදාහරණයක් ලෙස:

Decimal 9 in base 2 is 1001, which matches its BCD representation.
පාදම 2 හි දශම 9,  1001 වන අතර එය එහි BCD නිරූපණයට ගැලපේ.
