2. Which of the following best describes the correct sequence of operations in the Fetch-Execute Cycle of a
CPU?
CPU එකක ආහරණ ක්‍රියාකරවුම් චක්‍රයේ නිවැරදි මෙහෙයුම් අනුපිළිවෙල පහත සඳහන් ඒවායින් වඩාත් හොඳින්
විස්තර කරන්නේ කුමක්ද?

1) Execute → Decode → Fetch / ක්‍රියාත්මක කිරීම → විකේතනය → ලබා ගැනීම
2) Fetch → Execute → Decode / ලබා ගැනීම → ක්‍රියාත්මක කිරීම → විකේතනය
3) Decode → Fetch → Execute / විකේතනය → ලබා ගැනීම → ක්‍රියාත්මක කිරීම
4) Fetch → Decode → Execute / ලබා ගැනීම → විකේතනය → ක්‍රියාත්මක කිරීම
5) Decode → Execute → Fetch / විකේතනය → ක්‍රියාත්මක කිරීම → ලබා ගැනීම

Answer : 4)

• Fetch: The CPU starts by fetching (retrieving) the instruction from the memory. This is the first step
because the processor needs to know what operation to perform.
ලබා ගැනීම: CPU එක ආරම්භ වන්නේ මතකයෙන් උපදෙස් ලබා ගැනීමෙන් ය. මෙය පළමු පියවර
වන්නේ සකසනය සිදු කළ යුතු මෙහෙයුම දැන සිටිය යුතු බැවිනි.

• Decode: After fetching the instruction, the CPU decodes it to understand what actions are required.
This step translates the instruction into signals that control other parts of the CPU.
විකේතනය: උපදෙස් ලබා ගැනීමෙන් පසු, අවශ්‍ය ක්‍රියාමාර්ග තේරුම් ගැනීමට CPU එක එය විකේතනය
කරයි. මෙම පියවර උපදෙස් CPU හි අනෙකුත් කොටස් පාලනය කරන සංඥා බවට පරිවර්තනය කරයි.

• Execute: Finally, the CPU executes the decoded instruction, performing the operation such as
arithmetic calculations, moving data, or controlling input/output.
ක්‍රියාත්මක කිරීම: අවසාන වශයෙන්, CPU විකේතනය කළ උපදෙස් ක්‍රියාත්මක කරයි, අංක ගණිත ගණනය
කිරීම්, දත්ත ගෙනයාම හෝ ආදාන/ප්‍රතිදානය පාලනය කිරීම වැනි ක්‍රියාවන් සිදු කරයි.

Any other order wouldn’t work because you must first get the instruction (fetch) before you can
understand (decode) and carry it out (execute). For example, you cannot execute an instruction before
fetching it, or decode before fetching it.
වෙනත් ඕනෑම අනුපිළිවෙලක් ක්‍රියා නොකරනු ඇත, මන්ද ඔබට තේරුම් ගැනීමට (විකේතනය කිරීමට) සහ
එය ක්‍රියාත්මක කිරීමට (ක්‍රියාත්මක කිරීමට) පෙර ඔබ මුලින්ම උපදෙස් ලබා ගත යුතුය. උදාහරණයක් ලෙස,
ඔබට එය ලබා ගැනීමට පෙර උපදෙස් ක්‍රියාත්මක කළ නොහැක, නැතහොත් එය ලබා ගැනීමට පෙර
විකේතනය කළ නොහැක.

So, the logical and standard order is Fetch → Decode → Execute. Which is the answer option 4)
එබැවින්, තාර්කික සහ සම්මත අනුපිළිවෙල ලබා ගැනීම → විකේතනය → ක්‍රියාත්මක කිරීම වේ. පිළිතුරු
විකල්පය 4) වේ.
