1. A teacher creates a program to calculate the total marks of a student. If a student enters "ten" instead of
10, an error is shown by the program.
ගුරුවරයෙක්, ශිෂ්‍යයෙකුගේ මුළු ලකුණු ගණනය කිරීම සඳහා වැඩසටහනක් නිර්මාණය කරයි. ශිෂ්‍යයෙකු 10
වෙනුවට “දහය” ඇතුළත් කළහොත්, වැඩසටහන මඟින් දෝෂයක් පෙන්වයි.

Which type of data validation would detect this error?
මෙම දෝෂය හඳුනාගන්නේ කුමන ආකාරයේ දත්ත වලංගුකරණයකින්ද?

1) Range check / පරාස පරීක්ෂාව
2) Presence check / තථ්‍යතා පරීක්ෂාව
3) Uniqueness check / අනන්‍යතා පරීක්ෂාව
4) Length check / දිග පරීක්ෂාව
5) Type check / වර්ග පරීක්ෂාව
