1. What type of data access method is used by magnetic tapes?
චුම්බක පටි භාවිතා කරන්නේ කුමන ආකාරයේ දත්ත ප්‍රවේශ ක්‍රමයක්ද?

1) Random access /සසම්භාවි ප්‍රවේශය
2) Sequential access / අනුක්‍රමික ප්‍රවේශය
3) Direct access / සෘජු ප්‍රවේශය
4) Index access / දර්ශක ප්‍රවේශය
5) Parallel access / සමාන්තර ප්‍රවේශය

Answer : 2)

Explanation / පැහැදිලි කිරීම

Magnetic tapes use sequential access as their primary data access method. This means that data is read or
written in a linear order, one piece at a time, starting from the beginning of the tape and moving forward
until the required data is found. Unlike random access devices, where any location can be directly
accessed, magnetic tapes require scanning through intermediate data to reach a specific point. Therefore,
accessing data on tapes is slower when compared to modern storage devices like hard drives and solid-
state drives that support direct or random access. Sequential access makes magnetic tapes suitable for
storing large backups and archival data rather than frequent data retrieval.
