1. What is cloud computing primarily used for?
වලාකුළු පරිගණනය මූලික වශයෙන් භාවිතා කරන්නේ කුමක් සඳහාද?
1) Running operating systems on remote servers.
දුරස්ථ සේවාදායකයන් මත මෙහෙයුම් පද්ධති ධාවනය කිරීම

2) Storing data and providing computing resources over the internet.
අන්තර්ජාලය හරහා දත්ත ගබඩා කිරීම සහ පරිගණක සම්පත් සැපයීම.

3) Developing mobile applications / ජංගම යෙදුම් සංවර්ධනය කිරීම.
4) Building hardware devices / දෘඩාංග උපාංග තැනීම.
5) Encrypting network traffic / ජාල ගමනාගමනය සංකේතනය කිරීම.

5) The introduction of artificial intelligence / කෘතිම බුද්ධිය හඳුන්වාදීම
