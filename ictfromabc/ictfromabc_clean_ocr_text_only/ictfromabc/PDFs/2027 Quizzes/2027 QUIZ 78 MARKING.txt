2. What is a type memory, in which data can only be written once and cannot be erased?
දත්ත එක් වරක් පමණක් ලිවිය හැකි සහ මකා දැමිය නොහැකි ආකාරයේ මතකයක් වන්නේ පහත ඒවායින්
කුමක්ද?
1)  PROM
2)  EPROM
3) EEPROM
4) RAM
5) None of the above
ඉහත කිසිවක් නොවේ
Answer : 1)

Explanation / පැහැදිලි කිරීම:

The type of memory where data can only be written once and cannot be erased is PROM (Programmable
Read-Only Memory). PROM allows data to be programmed into it a single time, and once written, the
data becomes permanent and cannot be modified or deleted. This makes PROM suitable for applications
where data needs to remain unchanged.
දත්ත එක් වරක් පමණක් ලිවිය හැකි සහ මකා දැමිය නොහැකි මතක වර්ගය PROM (Programmable Read-
Only Memory) වේ. PROM මඟින් දත්ත එක වරකට වැඩසටහන්ගත කිරීමට ඉඩ ලබා දෙන අතර, ලියා
ඇති පසු දත්ත ස්ථිර වන අතර වෙනස් කිරීමට හෝ මකා දැමීමට නොහැකිය. මෙය දත්ත නොවෙනස්ව
පැවතිය යුතු යෙදුම් සඳහා ඡඍධඵ සුදුසු කරයි.

Option 2) is incorrect because EPROM (Erasable Programmable Read-Only Memory) allows data to be
erased and reprogrammed using ultraviolet light. Option 3) is also incorrect since EEPROM (Electrically
Erasable Programmable Read-Only Memory) allows data to be erased and rewritten electrically multiple
times.
විකල්ප 2) වැරදියි, මන්ද EPROM (Erasable Programmable Read-Only Memory) පාරජම්බුල කිරණ
භාවිතයෙන් දත්ත මැකීමට සහ නැවත ක්‍රමලේඛනය කිරීමට ඉඩ සලසයි. විකල්ප 3) ද වැරදියි, මන්ද EEPROM
(Electrically Erasable Programmable Read-Only Memory) දත්ත මැකීමට සහ විද්‍යුත් වශයෙන් නැවත
ලිවීමට ඉඩ සලසයි.

Option 4) is incorrect because RAM (Random Access Memory) is a volatile memory where data can be
written, erased, and rewritten as needed, but it is lost when power is turned off.
විකල්ප 4) වැරදියි මන්ද RAM (Random Access Memory) යනු නශ්‍ය මතකයක් වන අතර එහිදී දත්ත
ලිවීමට, මකා දැමීමට සහ අවශ්‍ය පරිදි නැවත ලිවිය හැකි නමුත් බලය අක්‍රිය වූ විට එය නැති වී යයි.

Therefore, the correct answer is 1).
