volatile memory that can retain data even when the power is turned off. Unlike PROM (Programmable
Read-Only Memory), which can only be programmed once, EPROM can be erased and reprogrammed
multiple times. The erasure process is unique as it involves exposing the EPROM chip to ultraviolet (UV)
light through a small quartz window on the chip. This UV light exposure resets the memory cells,
effectively clearing all the stored data.
