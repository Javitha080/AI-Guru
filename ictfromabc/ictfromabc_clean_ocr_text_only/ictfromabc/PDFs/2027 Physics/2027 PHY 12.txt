1. How do IDE and SATA cables differ in terms of data transmission method?

1) IDE uses serial communication, SATA uses parallel
IDE අනුක්‍රමික සන්නිවේදනය භාවිතා කරන අතර SATA සමාන්තර සන්නිවේදනය භාවිතා කරයි.

2) IDE uses parallel communication, SATA uses serial
IDE සමාන්තර සන්නිවේදනය භාවිතා කරන අතර SATA අනුක්‍රමික සන්නිවේදනය භාවිතා කරයි.

3) Both IDE and SATA use parallel communication
IDE සහ SATA දෙකම සමාන්තර සන්නිවේදනය භාවිතා කරයි.

4) Both IDE and SATA use serial communication
IDE සහ SATA දෙකම අනුක්‍රමික සන්නිවේදනය භාවිතා කරයි.

5) IDE uses wireless transfer, SATA uses wired transfer
IDE රැහැන් රහිත හුවමාරුව භාවිතා කරයි, SATA  රැහැන්ගත හුවමාරුව භාවිතා කරයි.
