1. Which of the following storage devices primarily uses sequential access for data retrieval?
දත්ත ලබා ගැනීම සඳහා අනුක්‍රමික ප්‍රවේශය ප්‍රධාන වශයෙන් භාවිතා කරන්නේ පහත සඳහන් ගබඩා
උපාංගවලින් කවරක්ද?

1) Hard Disk Drive (HDD) / දෘඪ තැටි ධාවකය (HDD)
2) Solid State Drive (SSD) / ඝන-තත්ව ධාවකය (SSD)
3) Compact Disc (CD) / සංයුක්ත තැටිය (CD)
4) Magnetic Tape / චුම්බක පටි
5) USB Flash Drive / USB ෆ්ලෑෂ් ධාවකය

Answer : 4)

Explanation / පැහැදිලි කිරීම:

• Option/ විකල්ප 1
HDDs primarily use random access because the read/write head can move directly to any part of the disk
to access data. So, they are not sequential access devices.
HDDs ප්‍රධාන වශයෙන් අහඹු ප්‍රවේශය භාවිතා කරන්නේ කියවීමේ/ලිවීමේ හිසට දත්ත වෙත ප්‍රවේශ වීම සඳහා
තැටියේ ඕනෑම කොටසකට කෙලින්ම ගමන් කළ හැකි බැවිනි. එබැවින්, ඒවා අනුක්‍රමික ප්‍රවේශ උපාංග නොවේ.

• Option/ විකල්ප 2
SSDs also use random access since they access data electronically with no moving parts, allowing direct
access to any memory cell quickly.
චලන කොටස් නොමැතිව ඉලෙක්ට්‍රොනිකව දත්ත වෙත ප්‍රවේශ වන බැවින් SSDs අහඹු ප්‍රවේශය ද භාවිතා
කරයි, ඕනෑම මතක සෛලයකට ඉක්මනින් සෘජු ප්‍රවේශය ලබා දේ.

• Option/ විකල්ප 3
CDs are optical storage devices and generally support random access, as the laser can move to any part of
the disc to read data without reading everything before it sequentially.
CDs යනු දෘශ්‍ය ගබඩා උපාංග වන අතර සාමාන්‍යයෙන් අහඹු ප්‍රවේශයට සහය දක්වයි, මන්ද ලේසර් තැටියේ
ඕනෑම කොටසකට ගමන් කර ඊට පෙර සියල්ල අනුක්‍රමිකව කියවීමෙන් තොරව දත්ත කියවීමට හැකිය.

• Option/ විකල්ප 4
Magnetic tape is the classic example of a sequential access device. To read a particular piece of data, the
tape must be wound through all preceding data, making access slow and sequential.
චුම්බක පටි යනු අනුක්‍රමික ප්‍රවේශ උපාංගයක සම්භාව්‍ය උදාහරණයයි. නිශ්චිත දත්ත කැබැල්ලක් කියවීමට,
පටිය පෙර සියලුම දත්ත හරහා ඔතා ගත යුතු අතර, ප්‍රවේශය මන්දගාමී සහ අනුක්‍රමික කරයි.

• Option/ විකල්ප 5
USB flash drives use random access memory, allowing quick access to any location on the drive.
USB ෆ්ලෑෂ් ඩ්‍රයිව් අහඹු ප්‍රවේශ මතකය භාවිතා කරයි, ධාවකයේ ඕනෑම ස්ථානයකට ඉක්මන් ප්‍රවේශය ලබා
දෙයි.

Therefore the answer is 4)
එබැවින් පිළිතුර 4) වේ.

2. Which of the following best describes random access in storage devices?
ගබඩා උපාංගවල අහඹු ප්‍රවේශය පහත සඳහන් ඒවායින් වඩාත් හොඳින් විස්තර කරන්නේ කුමක්ද?

1) Data is accessed only in the order it was written.
දත්ත ප්‍රවේශ වන්නේ එය ලියා ඇති අනුපිළිවෙලට පමණි.

2) The device must scan all previous data to reach the target.
ඉලක්කයට ළඟා වීමට උපාංගය පෙර සියලු දත්ත පරිලෝකනය කළ යුතුය.

3) Any data location can be directly accessed without following a sequence.
අනුපිළිවෙලක් අනුගමනය නොකර ඕනෑම දත්ත ස්ථානයකට සෘජුවම ප්‍රවේශ විය හැකිය.

4) Only recently used data can be accessed quickly.
මෑතකදී භාවිතා කළ දත්ත පමණක් ඉක්මනින් ප්‍රවේශ විය හැකිය.

5) Data access always begins from the first memory block.
දත්ත ප්‍රවේශය සෑම විටම පළමු මතක කොටසෙන් ආරම්භ වේ.

Explanation / පැහැදිලි කිරීම:

• Option/ විකල්ප 1
This describes sequential access, not random access. Devices with sequential access, like magnetic tapes,
require reading data in the order it was stored.
මෙය අහඹු ප්‍රවේශය නොව අනුක්‍රමික ප්‍රවේශය විස්තර කරයි. චුම්බක පටි වැනි අනුක්‍රමික ප්‍රවේශයක් ඇති
උපාංග, එය ගබඩා කළ අනුපිළිවෙලට දත්ත කියවීම අවශ්‍ය වේ.

• Option/ විකල්ප 2
Again, this refers to sequential access. If a device must scan data before the target, it cannot directly
jump to a specific location, which is not random access.
නැවතත්, මෙය අනුක්‍රමික ප්‍රවේශයට යොමු වේ. උපාංගයක් ඉලක්කයට පෙර දත්ත පරිලෝකනය කළ යුතු

This refers to cache or memory behavior (like RAM or CPU cache) but does not define random access in

• Option/ විකල්ප 5
This again describes sequential access. In random access devices, you don’t have to start from the first
block.
මෙය නැවතත් අනුක්‍රමික ප්‍රවේශය විස්තර කරයි. අහඹු ප්‍රවේශ උපාංගවල, ඔබ පළමු කොටසෙන් ආරම්භ
කළ යුතු නැත.

Therefore the answer is 3)
