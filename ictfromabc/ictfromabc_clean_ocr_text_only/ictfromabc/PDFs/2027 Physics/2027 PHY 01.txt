1. Which characteristic most fundamentally distinguishes Platform as a Service (PaaS) from Infrastructure
as a Service (IaaS)?
සේවාවක් ලෙස පසුතල (PaaS) සහ සේවාවක් ලෙස යටිතල පහසුකම් (IaaS) අතර වෙනස හඳුනා ගන්නේ
කුමන ලක්ෂණයෙන්ද?

1) PaaS includes physical networking hardware / PaaS හි භෞතික ජාලකරණ දෘඩාංග ඇතුළත් වේ
2) IaaS manages software deployment environments.
IaaS මෘදුකාංග යෙදවුම් පරිසරයන් කළමනාකරණය කරයි.
3) PaaS abstracts server management from developers.
PaaS සංවර්ධකයින්ගෙන් සේවාදායක කළමනාකරණය වියුක්ත කරයි

4) IaaS restricts users to preconfigured runtimes
IaaS මගින් පරිශීලකයන්ව පෙර වින්‍යාස කළ ධාවන වේලාවන්ට සීමා කරයි

5) PaaS offers no scalability for application hosting
PaaS යෙදුම් සත්කාරකත්වය සඳහා පරිමාණය කිරීමේ හැකියාවක් ලබා නොදේ

2. Which web hosting model provides each user with a fully isolated operating system instance while still
sharing the same physical server?
එකම භෞතික සේවාදායකය බෙදා ගනිමින් සෑම පරිශීලකයෙකුටම සම්පූර්ණයෙන්ම හුදකලා මෙහෙයුම් පද්ධති
අවස්ථාවක් ලබා දෙන වෙබ් සත්කාරක ආකෘතිය කුමක්ද?

1) Shared hosting / බෙදාගත් සත්කාරකත්වය
2) Cloud hosting / වලාකුළු සත්කාරකත්වය
3) Virtual Private Server hosting / අතථ්‍ය පුද්ගලික සේවාදායක සත්කාරකත්වය
4) Dedicated server hosting / කැපවූ සේවාදායක සත්කාරකත්වය
5) Reseller hosting / නැවත විකුණුම්කරු සත්කාරකත්වය

3. In an IaaS model, which of the following components is the consumer explicitly responsible for
configuring and managing?
IaaS ආකෘතියක, වින්‍යාස කිරීම සහ කළමනාකරණය කිරීම සඳහා පාරිභෝගිකයා පැහැදිලිවම වගකිව යුත්තේ
පහත සඳහන් කුමන සංරචකයද?

1) Hypervisor layer / හයිපර්වයිසර ස්ථරය

4) Data center networking infrastructure / දත්ත මධ්‍යස්ථාන ජාලකරණ යටිතල පහසුකම්
5) Virtual machine instances and operating systems / අතථ්‍ය යන්ත්‍ර අවස්ථා සහ මෙහෙයුම් පද්ධති

5. Which of the following best describes the difference between SaaS and PaaS?
SaaS සහ PaaS අතර වෙනස පහත සඳහන් ඒවායින් වඩාත් හොඳින් විස්තර කරන්නේ කුමක්ද?

1) SaaS provides virtual machines while PaaS provides storage services
SaaS අථත්‍ය යන්ත්‍ර සපයන අතර PaaS ගබඩා සේවා සපයයි

2) SaaS allows users to develop applications, whereas PaaS only allows application access.
SaaS පරිශීලකයින්ට යෙදුම් සංවර්ධනය කිරීමට ඉඩ දෙන අතර PaaS යෙදුම් ප්‍රවේශය පමණක් ඉඩ දෙයි.

3) SaaS delivers fully functional applications to end-users, while PaaS offers tools and platforms for
developers to build and deploy applications.
SaaS අවසාන පරිශීලකයින්ට පූර්ණ ක්‍රියාකාරී යෙදුම් ලබා දෙන අතර PaaS යෙදුම් ගොඩනැගීමට සහ
යෙදවීමට සංවර්ධකයින් සඳහා මෙවලම් සහ වේදිකා ලබා දෙයි.

4) SaaS is a type of private cloud, and PaaS is a type of public cloud.
SaaS යනු පුද්ගලික වලාකුළු වර්ගයක් වන අතර PaaS යනු පොදු වලාකුළු වර්ගයකි.

5) SaaS gives network-level control, while PaaS provides physical hardware access.
SaaS ජාල මට්ටමේ පාලනයක් ලබා දෙන අතර PaaS භෞතික දෘඩාංග ප්‍රවේශය සපයයි.

වේ.

නොහැක.

එය ප්‍රධාන වශයෙන් කලාත්මක නිර්මාණ සහ මාධ්‍ය නිෂ්පාදනය සඳහා පමණක් භාවිතා කරයි.
