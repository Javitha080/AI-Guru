1. Which of the following statements about Binary Coded Decimal (BCD) is correct?

1) In BCD, each decimal digit is represented using 8 bits.
BCD හි, සෑම දශම ඉලක්කමක්ම බිටු 8 ක් භාවිතයෙන් නිරූපණය කෙරේ.

2) BCD represents the entire decimal number as one binary value.
BCD මඟින් සම්පූර්ණ දශම සංඛ්‍යාව එක් ද්විමය අගයක් ලෙස නිරූපණය කරයි.

3) In BCD, each decimal digit is represented separately using 4 binary bits.
BCD හි, සෑම දශම ඉලක්කමක්ම ද්විමය බිටු 4ක් භාවිතයෙන් වෙන වෙනම නිරූපණය කෙරේ.

4) BCD is more efficient in storage than pure binary representation.
BCD ගබඩා කිරීමේදී ද්විමය නිරූපණයට වඩා කාර්යක්ෂම වේ.

5) BCD can represent digits from 0 to 15 using 4 bits.
BCD වලට බිටු 4ක් භාවිතා කරමින් 0 සිට 15 දක්වා ඉලක්කම් නියෝජනය කළ හැක.
