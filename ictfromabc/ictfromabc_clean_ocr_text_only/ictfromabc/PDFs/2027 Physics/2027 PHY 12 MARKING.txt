Answer : 2)

The correct answer is 2) IDE uses parallel communication, SATA uses serial. IDE, also known as PATA,
transfers data using parallel communication, where multiple bits are sent at the same time across wide
ribbon cables. While this method was common in older systems, it had limitations such as bulky cables,
lower data transfer rates, and issues like crosstalk and signal interference when speeds increased. SATA,
on the other hand, uses serial communication, where data is transmitted one bit at a time through thinner
and more flexible cables. This serial method allows SATA to achieve much higher speeds, improved
reliability, and better airflow inside the computer case.

The correct answer is 2) They are located on the CPU chip itself.

Registers are considered the fastest memory because they are built directly inside the CPU chip. Since
they are physically closest to the processor’s control unit and arithmetic logic unit (ALU), data can be
accessed and processed instantly without delays caused by traveling through buses like with cache or
RAM. This direct placement eliminates latency, making registers the quickest storage medium in a
computer system.
