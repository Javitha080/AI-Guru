1.  Which of the following best defines a logic gate?
පහත සඳහන් ඒවායින් තාර්කික ද්වාරයක් වඩාත් හොඳින් අර්ථ දක්වන්නේ කුමක්ද?

1) A device that stores data in binary form
ද්විමය ආකාරයෙන් දත්ත ගබඩා කරන උපාංගයක්
2) A device that performs a specific logical operation on one or more inputs to produce an output
ප්‍රතිදානයක් නිපදවීම සඳහා එක් හෝ වැඩි ආදාන මත නිශ්චිත තාර්කික මෙහෙයුමක් සිදු කරන
උපාංගයක්
3) A component used only in power circuits
බල පරිපථවල පමණක් භාවිතා කරන සංරචකයක්
4) A device that converts AC to DC
AC DC බවට පරිවර්තනය කරන උපාංගයක්
5) A device that generates random numbers
අහඹු සංඛ්‍යා ජනනය කරන උපාංගයක්

Answer: 2)

A logic gate is an electronic device that performs a specific logical operation (such as AND, OR, NOT)
on one or more binary inputs and produces a single binary output.
තාර්කික ද්වාරයක් යනු ද්විමය ආදාන එකක් හෝ කිහිපයක් මත නිශ්චිතතාර්කික මෙහෙයුමක්
(AND, OR, NOT වැනි) සිදු කරන සහ තනි ද්විමය ප්‍රතිදානයක් නිපදවන  ඉලෙක්ට්‍රොනික උපාංගයකි.

Therefore the correct answer is option 2).  / එබැවින් නිවැරදි පිළිතුර විකල්ප 2 වේ.

2.  A 3-input AND gate with inputs A, B, C produces output 1 only under which condition?
A, B, C ආදාන සහිත 3-ආදාන AND ද්වාරයක් ප්‍රතිදානය 1 නිපදවන්නේ කුමන කොන්දේසිය යටතේද?

1) Only when any two inputs are 1
ඕනෑම ආදාන දෙකක් 1 වන විට පමණි
2) Only when all three inputs are 1
ආදාන තුනම 1 වන විට පමණි
3) Only when A = 1, B = 0, C = 1
A = 1, B = 0, C = 1 වන විට පමණි
4) When at least one input is 0
අවම වශයෙන් එක් ආදානයක් 0 වන විට
5) When at least two inputs are 0
අවම වශයෙන් ආදාන දෙකක් 0 වන විට

Answer: 2)

An AND gate follows the rule that the output is 1 only if every input is 1.
සෑම ආදානයක්ම 1 නම් පමණක් ප්‍රතිදානය 1 වන බව AND ද්වාර රීතිය අනුගමනය කරයි.

For a 3-input AND gate, inputs A, B, and C must all be 1 at the same time to produce output 1.
ආදාන 3 AND ද්වාරයක් සඳහා, ප්‍රතිදානය 1 නිපදවීමට A, B සහ C ආදාන එකවර 1 විය යුතුය.

If any one of the inputs is 0, the output will be 0.
ආදාන වලින් එකක් 0 නම්, ප්‍රතිදානය 0 වනු ඇත.

Therefore the correct answer is option 2). / එබැවින් නිවැරදි පිළිතුර විකල්ප 2 වේ.

3.  Consider a logic circuit:
තාර්කික පරිපථයක් සලකා බලන්න:

Gate1: 2-input OR (A, B) → output X

Gate2: 3-input OR (X, C, D) → output Y

Which input combination will produce Y = 1?
Y = 1 නිපදවන ආදාන සංයෝජනය කුමක්ද?

1) A=0, B=0, C=0, D=0
2) A=1, B=0, C=0, D=0
3) A=0, B=0, C=0, D=1
4) A=0, B=1, C=0, D=0
5) All of the above except option 1 / විකල්පය 1 හැර ඉහත සියල්ල

Answer: 5)

Gate 1 (OR gate):
ද්වාරය 1 (OR ද්වාරය):
X = A OR B → X becomes 1 if either A or B is 1.
A හෝ B 1 නම් X → A OR B → X 1 වේ.

Gate 2 (OR gate):
ද්වාරය 2 (OR ද්වාරය):
Y = X OR C OR D → Y becomes 1 if any one of X, C, or D is 1.
X, C හෝ D වලින් ඕනෑම එකක් 1 නම් Y=X OR C OR D → Y 1 වේ.

Now check the options:
දැන් විකල්ප පරීක්ෂා කරන්න:

Option 1: All inputs are 0 → X = 0, Y = 0
විකල්ප 1: සියලුම ආදාන 0 → X = 0, Y = 0 වේ
Options 2, 3, 4: At least one input is 1 → X or C or D becomes 1 → Y = 1
විකල්ප 2, 3, 4: අවම වශයෙන් එක් ආදානයක් 1 → X හෝ C හෝ D 1 → Y  = 1 වේ

Therefore the correct answer is option 5).
එබැවින් නිවැරදි පිළිතුර විකල්පය 5 වේ.
