1. Which of the following correctly describes BCD representation?

1) A number is stored in pure binary form
සංඛ්‍යාවක් පිරිසිදු ද්විමය ආකාරයෙන් ගබඩා කර ඇත

සෑම දශම සංඛ්‍යාංකයක්ම ද්විමය බිටු 3 ක කණ්ඩායමකින් නිරූපණය කෙරේ

3) Each decimal digit is represented by a group of 4 binary bits
සෑම දශම සංඛ්‍යාංකයක්ම ද්විමය බිටු 4 ක කණ්ඩායමකින් නිරූපණය කෙරේ

4) BCD can represent negative numbers only
BCD හට සෘණ සංඛ්‍යා පමණක් නිරූපණය කළ හැකිය

දශම සංඛ්‍යා ගබඩා කිරීම සඳහා BCD ෂඩ් දශම සංඛ්‍යා භාවිතා කරයි

Answer: 3)

Explanation / පැහැදිලි කිරීම
BCD stands for Binary Coded Decimal. / BCD යනු Binary Coded Decimal වේ.
In BCD, each decimal digit (0–9) is encoded separately using 4 bits.
BCD හි, සෑම දශම ඉලක්කමක්ම (0–9) බිටු 4ක් භාවිතයෙන් වෙන වෙනම කේතනය කර ඇත.

Example:
7 → BCD 0111
25 → BCD 0010 0101
(2 = 0010, 5 = 0101)

So each digit gets its own 4-bit binary code.
එබැවින් සෑම ඉලක්කමකටම තමන්ගේම බිටු 4ක ද්විමය කේතයක් ලැබේ.

Therefore the answer is 3) / එබැවින් පිළිතුර 3) වේ.
