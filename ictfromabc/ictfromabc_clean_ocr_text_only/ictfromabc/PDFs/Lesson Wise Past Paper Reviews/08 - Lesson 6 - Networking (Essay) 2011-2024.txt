Honeypots are specially designed security systems that imitate vulnerable targets to attract cyber attackers.
Their main function is to detect, analyze, and learn about intrusion attempts without risking actual network
resources. These decoy systems lure hackers into interacting with fake data and services, allowing
administrators to study attack techniques, gather threat intelligence, and strengthen real systems based on
the findings. Honeypots are useful tools in proactive defense strategies and cyber threat research.

e Use of Network Address Translation

ජාල ලිපින පරිවරතනය භාවිතය (NAT)

The organization has only one public IP address (192.248.17.1), but 100 computers need access to the
Internet for web browsing. To solve this, Network Address Translation (NAT) is implemented on the
router. NAT allows all internal (private) IP addresses to be mapped to the single public IP address when

A Demilitarized Zone (DMZ) in networking is a special subnet that acts as a buffer zone between an
organization’s internal network and the public Internet. It contains services that need to be accessible from
outside the organization, such as web servers, mail servers, and FTP servers. These servers are assigned
public IP addresses so users on the Internet can access them, but they are placed in a separate network
segment to reduce the risk to the internal network.

When a computer in the internal network sends a packet to the Internet, the proxy server changes the
source IP address from the internal private IP (e.g. 10.0.0.20) to its own public IP (e.g. 123.45.67.10). The
destination IP remains the same. This makes it appear as if the request 15 coming from the proxy server,
not the internal computer. When the response comes back from the Internet, the proxy server receives it
and forwards it to the correct internal computer.

Parity Check / සමතා පරීක්ෂාව

Parity checking is a basic error detection technique used in digital communication systems to ensure
that data is transmitted without errors. It works by adding an extra bit, called the parity bit, to a set
of data bits. The role of the parity bit is to make sure that the total number of 1's in the data (including
the parity bit) follows a certain rule, which can be either odd or even parity.
