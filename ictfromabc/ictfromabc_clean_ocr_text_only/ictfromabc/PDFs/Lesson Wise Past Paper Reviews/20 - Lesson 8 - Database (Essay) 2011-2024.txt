Primary key of a table and foreign key of a table establish the relationship in a database.
වගුවක ප්‍රාට්මික යතුර සහ වගුවක ආගන්තුක යතුර දුත්ත සමුදායක සම්බන්ධතාවය AOS කරයි.

Explanation / පැහැදිලි කිරීම:

In relational databases, a primary key and a foreign key are used to maintain relationships between tables.
සම්බන්ධතා EDM සමුදායන්හි, ප්‍රාටමික යතුරක්‌ සහ ආගන්තුක යතුරක්‌ වගු අතර සම්බන්ධතා පවත්වා ගැනීමට
භාවිතා කරයි.

Primary Key / ප්‍රාටරමික යතුර

A primary key is a column (or set of columns) in a table that uniquely identifies each record.
ප්‍රාටමික යතුරක්‌ යනු එක්‌ එක්‌ QHOMO අනන්‍ය ලෙස හඳුනා ගන්නා වගුවක තීරැවකි (හෝ තීරැ කටිටලයකි).
It cannot be null and must be unique / එය ශුන්‍ය විය නොහැකි අතර ආවේණික විය යුතුය.

Each table has only one primary key / සැම වගුවකටම ඇත්තේ එක්‌ ප්‍රාටමික යතුරක්‌ පමණි.

Foreign Key / ආගන්තුක යතුර

A foreign key is a column in one table that refers to the primary key in another table.

ආගන්තුක යතුරක්‌ යනු තවත්‌ වගුවක HOG යතුර සඳහන්‌ කරන එක්‌ වගුවක HOH.

It is used to create a relationship between two tables.

එය වගු දෙකක්‌ අතර සමිබඛන්ධතාවයක්‌ නිර්මාණය කිරීමට භාවිතා කරයි.

It can have duplicate values and may allow NULLs (unless restricted).

එයට අනුපිටපන්‌ අගයන්‌ තිබිය හැකි අනර හිස්‌ අගයයන්‌ වලට ඉඩ දිය හැකිය (සීමා කර නොමැති HG).

(INF) ee. වගුවේ ප්‍රාට්මික යතුර CNo (contract number) වේ.

There are no partial dependencies because all non-key attributes (like AName, AMobile, Client) depend

only on a part of the key.
