When programs run and end, they leave behind small scattered free spaces in memory called holes. Even
if the total free space is enough, these gaps may be too small to fit new programs. This problem is called
external fragmentation, where memory is available but not usable efficiently.

Compaction moves memory blocks closer together to create one large, continuous free space. This
removes small gaps and helps reduce fragmentation.

Even if there is sufficient physical memory, the operating system may still need to swap out some pages
to make room for new ones.

This is because the operating system uses page replacement algorithms to decide which pages to evict

Contiguous Allocation / යාබඳ විභජනය
