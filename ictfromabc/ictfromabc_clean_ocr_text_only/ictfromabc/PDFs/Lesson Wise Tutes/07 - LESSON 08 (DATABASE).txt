The Object-Relational Database (ORD)
model is a hybrid approach that combines
features of both relational databases and
object-oriented databases.

වස්තු සම්බන්ධතා දත්ත සමුදා (ORD) ආකෘතිය

චිකාබද්ධ කරන දෙමුහුන්‌ ප්‍රවේශයකි.

It extends the traditional relational
database model by incorporating elements

methods, into the relational framework.

allows you to uniquely identify the value of
B.
